# heronprecision.com

The source of [heronprecision.com](https://heronprecision.com), the website of Heron Precision
LLC. It is one static page, served as-is by GitHub Pages. There is no build step and no
framework, and it loads no third-party scripts, fonts, or trackers.

## Files

| File | What it is |
|---|---|
| `index.html` | The page, with its styles and script inline |
| `tokens.css`, `ui-tokens.css` | Color, motion, and spacing tokens from the Heron Precision brand system |
| `fonts/AdwaitaSans.woff2` | A Latin subset of Adwaita Sans |
| `fonts/OFL-1.1.txt` | The font's license |
| `favicon.svg` | The site icon |
| `card.png` | The image shown when the link is shared, generated by `tools/card.py` |
| `tools/` | Scripts that capture the page as images and animations |
| `CNAME`, `.nojekyll` | GitHub Pages settings: the custom domain, and serving files without Jekyll |

## Viewing It Locally

The page uses root-relative paths, so serve the folder rather than opening the file:

```sh
python3 -m http.server 8765
```

Then open <http://localhost:8765/>.

## Motion and Accessibility

The page assembles itself once on load, and each section as it scrolls into view. Every
transition takes 320 ms or less; the two fields below are small simulations rather than
transitions, and draw only while something is changing.

The plot beside the headline is a small simulation, not a recording. Over a faint fiber layup, a
vehicle with a limited turn rate flies between waypoints. Each waypoint it reaches spawns a new
one, so the route never repeats. Click the plot to add up to three waypoints of your own. Add
`?seed=N` to the address to replay the same route. On a narrow screen the plot runs behind the
headline, quieter, and does not take taps.

Behind *What We Build* is a layup: four plies of fiber at 0, +45, -45, and 90 degrees, the
order a composite part is built in. They are laid across the band one after another when it first
scrolls into view. Once laid, the two diagonals stay, never at the same weight: they lean against
each other over about forty seconds, and soft patches of extra weight drift along each one's own
fibers, so one corner of the band can lean one way while another leans the other. The whole stack
shows through around a mouse pointer. A click or tap lights the fiber under it: the light runs along
the fiber both ways and forks onto crossing fibers, each fork fading faster than the last. Now and
then a fainter one lights on its own. Each ply is a small repeating tile, so the browser composites
the lay-in, the drift and the pointer rather than redrawing them.

With reduced motion requested in the operating system (`prefers-reduced-motion: reduce`), the page
renders finished with no animation, the plot shows a single still frame, and the band shows
its top ply, still.

## Tools

The scripts in `tools/` drive Chromium through Playwright (`pip install playwright pillow`):

- `still.py` captures the full page after it has finished assembling.
- `cast.py` records an animated GIF, optionally cropped, with timed clicks, pointer moves, and scrolls.
  Set `CAST_DPR=2` to record at high pixel density, which keeps the faint lines as they look on a
  sharp display.
- `card.py` builds `card.png`, the share image, from the top of the page.
- `gifsheet.py` lays out evenly spaced moments of a GIF as one labeled sheet.
- `gifshrink.py` makes a GIF smaller by scaling it, dropping frames, and reducing colors, keeping its length.

Each script's first lines give its usage. Rebuild `card.png` whenever the top of the page changes:

```sh
python tools/card.py card.png http://localhost:8765/?seed=3
```

## Font

Adwaita Sans is licensed under the SIL Open Font License 1.1; see `fonts/OFL-1.1.txt`. The subset
is rebuilt with fontTools:

```sh
pip install fonttools brotli
pyftsubset AdwaitaSans.ttf \
  --unicodes="U+0020-007E,U+00A0-00FF,U+2013,U+2014,U+2018,U+2019,U+201C,U+201D,U+2022,U+2026,U+2122" \
  --flavor=woff2 --layout-features='*' --output-file=fonts/AdwaitaSans.woff2
```
